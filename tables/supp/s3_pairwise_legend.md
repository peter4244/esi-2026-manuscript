**ST3. Pairwise contrasts among cross-classification groups for all outcomes.**

Wald contrasts on the log-effect scale between each pair of the three COPD-positive cross-classification groups (Both-COPD, CT-only-COPD, ESI-only-COPD), reported for each outcome (all-cause mortality, respiratory mortality, exacerbations). Estimates are the difference in log HR (mortality) or log IRR (exacerbations) between the two groups in the contrast; the standard error is the Wald SE from the fitted Cox model (mortality) or negative-binomial model (exacerbations). Adjusted p-values are single-step-adjusted within each outcome across the three contrasts using the multcomp package. These are the contrasts underlying main text Table 3. No contrast reached significance for any outcome at α = 0.05, so no significance letters are displayed there.

**Abbreviations:** HR, hazard ratio; IRR, incidence-rate ratio; Δlog, difference in log-effect (log HR for mortality, log IRR for exacerbations); SE, standard error; COPD, chronic obstructive pulmonary disease; CT, computed tomography; ESI, Emphysema Severity Index.
