**Supplementary Table S4a. Cardiovascular-disease-specific mortality by Bhatt-framework diagnostic category under both frameworks.**

Cause-specific Cox proportional-hazards models estimate the hazard ratio for cardiovascular-disease mortality relative to the noCOPD reference under each framework, with deaths from other causes treated as censored. Cause-of-death classification uses the National Death Index primary ICD-10 code mapped to the CVD chapter (I00–I99). Adjustment covariates are age, sex, race, current smoking status, pack-years, and body mass index. Category totals (Bhatt-framework, at risk): AFL-only-noCOPD n = 170, COPD-minor n = 1,099, COPD-major n = 3,969.

**Abbreviations:** CVD, cardiovascular disease; CT, computed tomography; ESI, Emphysema Severity Index; AFL, airflow limitation; HR, hazard ratio; CI, confidence interval; NDI, National Death Index; ICD-10, International Classification of Diseases, 10th revision.
