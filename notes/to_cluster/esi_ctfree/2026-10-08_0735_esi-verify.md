**What this is for.** Pete is running a five-step verification of the CT-free manuscript. Since 2026-10-08,
**COPDGene participant data are used only on Channing**, so the checks that need the data run here:
1. an independent recomputation of the paper's key statistics (`recompute_ctfree.R`, written separately from the
   analysis code), and
2. four result-correctness checks (`C1` cause-of-death coverage, `C2` a conventional-spirometry comparator,
   `C3` FEV1-model checks, `C4` join integrity). `C1`–`C4` re-run the analysis code up to the discordance section with
   all output redirected to a temporary folder; nothing in `ctfree/assets/` is written.

Everything this note creates is new: two script folders inside the existing reproduction clone, one job script, and
an output folder in `/d/tmp`. **It overwrites and deletes nothing.** Output is aggregate only (tables of counts,
rates and estimates); no participant ids or rows.
